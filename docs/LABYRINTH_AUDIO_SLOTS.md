# Labyrinth audio — resource-pack slots

Vanilla placeholders ship in `assets/millenaire/sounds.json`. Replace these events in a resource pack for custom SFX / OST stems without code changes.

| Sound event | Role | Suggested custom content |
|-------------|------|--------------------------|
| `millenaire:labyrinth.drone` | Zone presence bed (Arrival / Bleed / Orde) | Low cold drone, 8–20s loop |
| `millenaire:labyrinth.metal` | Corridor metal / chain ticks | Sparse metallic impacts |
| `millenaire:labyrinth.whisper` | Liminal domestic wrongness | Soft unintelligible whisper |
| `millenaire:labyrinth.chase_stinger` | Rammelaar blink telegraph | Short chase stinger |
| `millenaire:labyrinth.ruit_drone` | De Ruit / Approach presence | Rising geometric drone |

Subtitles: `subtitles.millenaire.labyrinth.*` in `en_us.json` / `nl_nl.json`.
